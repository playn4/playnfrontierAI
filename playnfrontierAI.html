The design lead

Three ideas nobody in the class ships together.

I

One screen. The whole house.

Generated, never hand-written. Staleness flags itself, prose never duplicates — and full catch-up costs ~1% of your context while the system underneath keeps growing.

II

Memory that audits its machine.

At every close, every claim is re-verified against the live system: files exist, models resolve, health agrees. If reality moved, memory says so — before you trust it.

III

Drift is impossible by design.

Project truth outranks episodic memory. Every session a receipt, every decision numbered, every supersession explicit. The market calls this unsolved. We call it Tuesday.

The unbenchmarkable axis: no published memory benchmark tests whether stored facts are still true, whether entries carry lineage, or whether the agent can prove readiness. OWASP flags memory poisoning as a top agentic risk; benchmark coverage is zero. This is the axis we're built for — and together, these three ideas run a frontier lab and remember all of it.
